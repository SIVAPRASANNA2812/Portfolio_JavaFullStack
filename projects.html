CareerNest — Enterprise Full-Stack Job Portal

Marquee full-stack capstone developed during the HCL / GUVI Executive Program. Connects employers and job seekers with a decoupled Spring Boot REST API, Twilio SMS notifications, token rotation security, and a responsive vanilla JS frontend deployed on Render Cloud.

HCL / GUVI Capstone • Backend

E-Commerce Backend System REST API

Production-grade E-Commerce backend service engineered during the HCL / GUVI Executive Program with Spring Boot and MongoDB, featuring Role-Based Access Control, zero-lock concurrency control, and transactional cart-to-order processing.

  • RBAC & Auth: Stateless JJWT authentication with BCrypt hashing across USER, ADMIN, and MANAGER roles.
  • Zero-Lock Concurrency: Leveraged MongoDB atomic conditional updates (findAndModify) preventing race conditions, inventory overselling, and inconsistencies during peak checkouts.
  • Transactional Workflow: 4-step order cycle (stock check → atomic deduction → order generation → cart wipe) with price locking (priceAtPurchase) and auto-restock on cancellation.
  • Idempotent Payments: Payment simulation engine with safe retry policies guaranteeing duplicate client requests never double-charge or corrupt state.
  • Cloud Deployment: Hosted on AWS EC2 and Render with SpringDoc OpenAPI 3 UI and RFC-compliant global error handling via @RestControllerAdvice.
